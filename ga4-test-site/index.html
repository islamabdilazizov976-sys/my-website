Tracking Validation & Event Audit

Is our GA4 data right?

A four-page test site used to check that Google Analytics 4 records the right events, with the right parameters, exactly once.

Why it matters

Marketing budgets and content decisions rely on analytics. A missing tag, a duplicated snippet or a misnamed parameter quietly distorts every report.

What we check

  • The event fires at all
  • The event name matches the plan
  • Parameters carry correct values
  • Each action is counted once

Our goal

A GA4 setup we can trust, with every fix tested and proven, and a validation process we can repeat after future changes.

Events to expect on this page

  • page_viewOn every page load, with page_location and page_title
  • session_startOn the first page of a visit
  • scrollOnce, at 90% depth (percent_scrolled = 90)

Test plan

Each test checks three things: the correct event name, the correct parameters, and exactly one recording per action. Run them with DebugView on, then repeat in Realtime.

Test modes

Add these to any page address while testing. The badge in the corner shows which mode is active.

Address ending Effect
?debug=1 Sends debug_mode so events appear in DebugView. Lasts for this tab session. Use ?debug=0 to stop.
?traffic_type=internal Marks this browser as internal traffic, so the GA4 data filter can exclude it. Saved until you open ?traffic_type=external.
