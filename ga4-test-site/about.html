About the project

About Team 6 Project

We audit event parameters, payload emissions, and data retention rules in GA4 for our Web Analytics project.

Objectives

  1. Verify GA4 event tracking end to end.
  2. Check event names against the measurement plan.
  3. Check event parameters for correct values.
  4. Identify missing and duplicated events.
  5. Review internal traffic and overall data quality.
  6. Recommend concrete tracking improvements.

In scope

  • Page views on all four pages
  • PDF downloads on Resources
  • Outbound clicks on Resources
  • Scroll events
  • Contact form events
  • Internal traffic review

Out of scope

  • Online payments
  • Shopping carts and purchase tracking
  • Server-side and unrelated systems

How we work

  1. PreparePages live; GA4 and DebugView ready.
  2. ActPerform user actions on the site.
  3. InspectCheck each event in DebugView.
  4. CompareCross-check activity in Realtime.
  5. VerifyValidate names and parameters.
  6. RecordLog results and flag problems.

Tools

Realtime Recent activity per user, top events Confirming data arrives
Browser DevTools Requests sent to /g/collect Checking payloads and duplicates

Challenges and planned solutions

Challenge Solution
Events not appearing Check tag installation on every page; verify with Tag Assistant.
Incorrect event parameters Review event configuration and parameter mapping in DebugView.
Duplicate tracking Check for a tag installed twice, for example a theme plus a manual snippet.
Internal traffic mixed in Define internal traffic and enable the filter in GA4.
Delayed standard reports DebugView and Realtime validate instantly; allow about 24 hours for standard reports.
